Panduan & Petunjuk Pengisian Sistem PERMATA

Ikuti langkah-langkah di bawah ini untuk mengisi formulir biodata dan pilihan konsumsi dengan benar.

Mode Aman & Terenkripsi
1

Form Pendaftaran Biodata

  • Klik menu "Form Pendaftaran" di sidebar kiri.
  • Isi **Nama Lengkap**, **Nama Panggilan**, dan pilih **Kecamatan** (Palu Selatan/Timur).
  • Pilih status **Marhala** (Takwin 1 atau Takwin 2).
  • Masukkan **Nomor WhatsApp**, **Pekerjaan**, dan **Alamat Domisili**.
  • Tekan **"Simpan Data Peserta"**. Data otomatis tersinkron ke Cloud Google Sheets.
2

Pilihan Menu Konsumsi

  • Buka menu "Pilihan Konsumsi".
  • Pilih nama Anda pada dropdown **"Pilih Nama Peserta Terdaftar"**.
  • **Centang salah satu** dari 8 pilihan varian menu makanan yang berjejer di layar.
  • Klik tombol **"Simpan Pilihan Makanan"**. Pilihan Anda akan tampil pada Rekapitulasi Pesanan.
3

Pencetakan & Save PDF

  • Klik tombol "Cetak / Save PDF" di header bagian atas.
  • Pilih jenis data yang ingin didownload (Data Peserta atau Data Konsumsi).
  • Pilih opsi **Save File PDF** untuk menyimpan laporan lengkap ke perangkat Anda.
4

Fitur Keamanan & Modul Admin

  • Data pribadi seperti No HP dan Alamat secara otomatis **tersamar (masked)** untuk publik.
  • Untuk membuka data sensitif atau menghapus data, klik **"Login Admin System"** dan masukkan PIN **1280**.
Butuh Bantuan Lebih Lanjut?

Jika nama Anda belum terdaftar di Pilihan Konsumsi, pastikan Anda telah mengisi Form Pendaftaran terlebih dahulu.

Opsi Cetak & Save PDF

Pilih jenis data dan metode output yang ingin Anda unduh atau cetak.
