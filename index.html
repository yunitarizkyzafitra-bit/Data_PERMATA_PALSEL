Integration Google Sheets (kode.gs)

Langkah Singkat Menghubungkan:

  1. Buka Google Spreadsheet baru di Google Drive Anda.
  2. Klik menu Extensions > Apps Script.
  3. Hapus semua kode bawaan, lalu paste file kode.gs yang telah diberikan.
  4. Klik Deploy > New Deployment.
  5. Pilih type Web app, atur Who has access menjadi Anyone.
  6. Klik Deploy, salin Web App URL, dan paste pada kolom di atas!
